# SmartreplyAI
💬 SmartReply AI

An AI-powered message writing assistant built with Python, Streamlit and the Google Gemini API. Paste any message or describe a situation, choose a tone and language, and get a ready-to-send reply in seconds.

SmartReply AI Screenshot

✨ Features
Generate a reply for any message (recruiter, interview invite, email, normal chat)
Choose a tone: Professional, Friendly, Formal, Casual, Confident
Choose the reply language: English, Hindi, Hinglish
Multiple modes:
Write a new reply
Improve my existing reply
Make it shorter
Make it more polite
Reply to a recruiter
Copy-ready output box
API key is kept private in a .env file

🚀 Setup and Installation (Windows)
1. Clone the repository
powershell
git clone https://github.com/Tarun0030/SmartReplyAI.git
cd SmartReplyAI
2. Create and activate a virtual environment
powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
3. Install dependencies
powershell
pip install -r requirements.txt
4. Get a Gemini API key
Open Google AI Studio
Click Get API key → Create API key
Copy the key
5. Create the .env file

In the project folder, create a file named .env and add:

GEMINI_API_KEY=your_gemini_api_key_here

Do not add quotes or spaces. Never share this key or upload it to GitHub.

6. Run the app
powershell
python -m streamlit run app.py

The app opens at http://localhost:8501.

⚙️ Configuration

The AI model name is set at the top of app.py:

python
MODEL = "gemini-3.8-flash"

Model names change over time. If you get a 404 NOT_FOUND error, check the error message or the Gemini API docs for the current model name.

🩺 Troubleshooting
Problem	Solution
File does not exist: app.py	Run the command from the folder that contains app.py
API key missing	Check that .env is in the project root and contains GEMINI_API_KEY
404 NOT_FOUND (model)	Update the MODEL value in app.py
429 error	Free-tier limit reached, wait a little and try again
ModuleNotFoundError	Activate the venv and run pip install -r requirements.txt
